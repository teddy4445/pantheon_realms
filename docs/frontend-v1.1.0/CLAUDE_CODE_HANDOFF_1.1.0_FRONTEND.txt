DESIGN SYSTEM
Use illustrated surfaces, carved rectangular controls, thin gold edges and a hierarchy of title, image, short copy and action. Keep ornament around content, not behind text. Avoid webpage navigation bars, oversize rounded cards, repeated technical chips, skeleton dashboards and large unused margins. Do not turn every setting into an icon-only mystery. Native controls can be visually restyled while preserving semantics.
Default shell is neutral dark blue/bronze, without branding every pre-game screen Greek. Selected faction can tint its banner, portrait frame and heading. Reuse the six distinct gui.frame.<faction> and gui.banner.<faction> assets for faction-specific panels. Do not show Greek symbols for Japanese/Celtic/Mesoamerican content.
Use an actual responsive grid inside the artwork. Do not position all text against absolute screenshot coordinates. One outer frame per major region; use lightweight CSS rules for dense internal rows. Follow the prior pack's tested nine-slice and per-faction surface insets, not a stretched full rectangular frame. Book content must fit the safe page rectangles; never stretch the spine across text. At small widths use a single parchment page with the same data and controls, rather than shrinking an entire book until unreadable.
Recommended scales: 1600x1000 reference, validate 1280x720 and 1920x1080, plus a narrow layout and 200% text zoom. Body text approximately 16–18 CSS px at default scale; controls at least 40 px high, 44 px on touch. Allow long localized labels and scroll panels. Keep footer actions visible without covering last rows. Dim background under modals and trap focus. Highlight selection with gold outline AND check/text; keyboard focus must be distinct from selection. Tooltips also appear on keyboard focus. All actions remain usable without hover.
Motion: brief 120–180ms focus/selection transitions; optional subtle backdrop crossfade. No constant camera movement, mandatory page-turn delay, parallax or automatic creature motion when reduced motion is active. The adventure map keeps its fixed angle; existing left/right/up/down panning and supported zoom remain. Turn-order rotation in Random Setup is a gameplay option, not camera rotation.
