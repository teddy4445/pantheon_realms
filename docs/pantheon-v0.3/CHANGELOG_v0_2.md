# Changes from the v0.1 Design and Screen Demo

**Status:** P - proposed revisions, not an implemented release.

| Area | Earlier state | v0.2 candidate |
| --- | --- | --- |
| Construction | Paid project, usually two days; one active project | Immediate completion; one building/upgrade per town per day |
| Economy | Small illustrative demo values | Hall-income ladder and explicit cost/growth tables |
| Combat | Move OR attack; independent initiative | Move plus melee; Speed-based round and waiting phases |
| Damage | Fixed base damage divided by defense factor | Damage range and capped Attack-minus-Defense modifier |
| Defend | 50% damage reduction | +20% effective Defense, explicitly rounded |
| Heroes | Six attributes, three offered skills | Four primary attributes; Movement derived, Leadership a skill; two offers |
| Recruiting | Four demo creature definitions | Eight Greek families, sixteen forms; seven active production tiers |
| Resources | Five-resource working model | Same five retained deliberately, contrasted with H3's seven |
| Main menu | Landing prototype plus review sidebar | Full resume/new/load/codex/settings flow and separate pause dialog |
| Settings | Basic review settings | Typed settings, defaults, persistence, accessibility and safe rollback |
| Unit information | Basic encyclopedia entries | S18 animated unit detail plus contextual stack inspector |
| Lore | Illustrative names | Historical-source notes, original game legends, and source status |
| Animation | Not specified | Non-binding visual style; precise playback/state/accessibility contract |

The 17 original screen IDs remain stable. S01 is expanded into Main Menu; S17 is expanded rather than duplicated; S16 becomes the reference index. S18 is the new Unit Detail screen. Supporting pause, save/load, inspection, confirmation, and endgame panels receive dialog IDs.

Archived documents are unchanged. No old test results are re-labeled as v0.2 test results. No code, save file, screenshot, sound, or generated image has been modified.
