## Closed versus still open

Technology and stylized 3D are no longer open. One upgrade per creature is no longer open. Exact dependency versions, supported OS release matrix, reference hardware, final art approval, audio production, final balance, full multiplayer services and the other mythologies are still open production details. The new campaign provides a concrete proposed implementation target without pretending these later concerns are finished.
