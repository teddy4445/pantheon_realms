# Documentation and website maintenance

These tools read the current game rather than copying numbers from older release notes. Run from the game repository root after `npm ci`. They need Node and the repository's Vite/Sharp dependencies; no external service or API key is required.

## Source atlas

```bash
node tools/docs/source-index.mjs
node tools/docs/source-index.mjs --check
node tools/docs/check.mjs
```

The atlas indexes production source, styles, app configuration, root configuration and tooling. It skips dependencies, build output and tests. Export extraction is intentionally lexical: the result is a navigation aid, not a TypeScript API compatibility report. Package guides describe architecture and supported imports. `check.mjs` verifies local links and image targets in current contributor documentation without contacting external hosts or auditing historical archives.

## Current content snapshot

```bash
node tools/docs/export-catalog.mjs
```

Vite bundles [catalog-entry.ts](catalog-entry.ts) for Node, which loads and validates the real catalog. The tool writes the human-readable count/chapter snapshot to `docs/development/content-snapshot.json` and a temporary complete catalog to `test-results/docs-catalog/catalog.json`. The latter feeds website synchronization and is not a public API or committed asset. Pass an optional date, such as `node tools/docs/export-catalog.mjs 2026-10-24`, to reproduce a release snapshot; otherwise it uses today's UTC date.

## Website city showcase

```bash
node tools/docs/export-catalog.mjs
node tools/docs/sync-website.mjs ../pantheon_realms_website
```

The destination must be the existing website checkout. This updates `game-data.js`, paints current city derivatives into `images/current-cities/`, and writes `production/current-city-provenance.json`. It preserves the website's authored construction sequence and checks that each step still fits the current building chains. Review that sequence when changing prerequisites; this tool is not a construction-legality solver.

The merged art manifests give the current city packs precedence over older records. Images are resized as website derivatives; game source/runtime originals are not modified. City placement requires the game's `sceneAspectRatio`, which is exported alongside the slots. Updating files does not deploy the website.

## README and gallery media

```bash
node tools/docs/prepare-media.mjs ../pantheon_realms_website
```

Creates lightweight WebP files under `docs/images/`, records their provenance and copies gameplay captures to the website's `images/release-1.0/`. The input list is intentionally curated in the script: replace it with verified new captures when showing a new feature. Cover/logo come from the website; gameplay screenshots come from the game's dated production folders. No imagery is generated by this tool.

## Before sharing

Check relative links, view the README with a Markdown renderer, and test the website at desktop/mobile widths. Confirm release metadata against the actual installer and set `site-config.js` to the intended HTTPS download URL. A file hash from a local build does not verify the permissions or content of a remote file-hosting page.
